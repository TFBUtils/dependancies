# the bat redirector 
-# (corny name i know)

anyways this is a bit of a QoL userscript, it makes it so that when you visit firebat's channel on youtube, it makes sure you're on the channel ID URL, rather than an @handle URL

it's mostly so that you have an easier time finding her channel in your browser history, since she has a strong history of changing her display name and handle name. (though handles are still associated with the account for a week after a change anyways)
